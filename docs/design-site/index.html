Source contract

每個數字先回答「從哪裡來」

介面層不得接收一個沒有 provenance 的裸數字。衍生與估算可以存在，但不能併入「實際」總額。

Aggregation只聚合相同語意與時間範圍；避免重疊 duration
UI contractvalue + unit + source + freshness + classification
01 · TOKENS

供應商欄位才叫 token

Codex rollout 有真實 input、cached input、output 與 reasoning output；Claude message usage 也可讀。字串長度換算只能叫 estimate，且預設不納入。

02 · COST

只顯示 API 標準費率等價值

ChatGPT／Claude 訂閱活動不能冒充 API 美元帳單。「實際扣款」不出現在介面；API-equivalent estimate 預設顯示，並標成非帳單與 rate version。

03 · TIME

三種時間不得混用

last activity、transcript span、active execution time 分欄。跨日誌、睡眠、重開機的 first-to-last span 不能標成「已運作」。

04 · PROJECT

cwd 或明確 mapping

先用 task 的 exact cwd，再用已保存的 projectId／user mapping。不能從 session title、plugin runner 或最後一段目錄猜。

05 · RELATIONSHIP

Explicit parent only

Claude nested path 已提供 main session ID 與 agent ID；讀不到 parent、或父紀錄不在本機索引時明示「找不到父 Session」，不假造樹狀關係。Claude 內部非 sidechain runtime 另列為獨立工作，不冒充專案 hierarchy。

06 · COVERAGE

缺欄位不冒充分析資料

0、1,800 RPM、預設 model、預設 32°C 都不是缺資料的替代品。分析型清單省略空欄位；安全控制若缺必要讀值則明示原因並 fail closed。

Lifecycle & user flow

Active 與 History 是狀態，不是檔案新舊

重開機不會刪除 Claude／Codex／Antigravity 的持久日誌，所以 24 或 86 小時的 transcript span 可能存在；它不是 live duration。只有活動 metadata 的紀錄永久保留，但 Recent／History 預設不混入用量分析。

Active

Codex latest turn 明確為 inProgress，或 matching provider process + project CWD + 30 秒內 transcript 活動。

enter: exact or cross-checked evidence
exit: turn ends or activity stops
Idle

同專案 provider 程序仍存在，但該 session 沒有近期 transcript 活動。

enter: process match only
exit: fresh activity or process exit
Recent Inactive

目前沒有 matching provider process，但最後活動仍在 24 小時內，方便續接與快速查找。

enter: no runtime evidence
exit: inactivity ≥ 24h
History

24 小時後移入永久索引；專案預設收合、分支每批 40 筆，且不在背景週期重掃。專案內另一個程序存在，不足以把歷史 session 標成 Idle。

retention: permanent
refresh: manual
delete UI: not covered
