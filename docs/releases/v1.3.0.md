# MacDashboard v1.3.0 — Trustworthy Dashboard & Safe Storage

MacDashboard v1.3.0 replaces plausible-looking fallback values with source-aware measurements, makes the AI session hierarchy usable at history scale, and adds measured storage composition with explicit cleanup boundaries.

## Highlights

- Rebuilt AI coding analytics around **project → main session → child session** with independent disclosure controls.
- Added separate **Active**, **Recent 24h**, and permanent **History** scopes. Large histories are collapsed and loaded in bounded batches.
- Added Codex local turn-state reconciliation. Claude and Antigravity use process, workspace, and transcript evidence and disclose that boundary.
- Preserved provider-reported token totals without double-counting cache or reasoning subsets.
- Replaced billing language with optional **API-equivalent estimates**. Estimates require a recognized model, usable provider token fields, and a versioned standard rate entry; they are never presented as actual charges.
- Fixed the estimate visibility toggle so it now applies consistently to project rows, session rows, and the selected-session evidence panel.
- Rebuilt thermal presentation around measured named points. On the tested Mac, the app exposed 3 source groups and 16 named points: 14 PMU/SoC, one AppleSmartBattery, and one NAND point.
- Fixed the SMC helper ABI payload and made fan capability depend on actual hardware RPM readback rather than a successful helper ping.
- Removed the misleading RAM purge action. macOS reclaims inactive pages automatically; `purge` only clears disk buffer cache.
- Added measured storage composition, an unclassified remainder, fixed allow-listed cleanup candidates, impact labels, explicit confirmation, cancellation, and post-action remeasurement.
- Kept Docker storage separate from ordinary cleanup and intentionally omitted volume-prune actions.
- Improved process attribution, secret-shaped command-line redaction, Docker metadata/status joins, sidebar navigation, and narrow-window readability.

## Evidence boundaries and known limits

- The downloadable app is ad-hoc signed and **not Apple-notarized**. macOS may require **System Settings → Privacy & Security → Open Anyway** on first launch.
- Temperature sources vary by Mac model and OS. The tested 3 groups / 16 points are not a universal hardware promise.
- Non-Codex providers do not expose an authoritative live-task API in every log format. Their status is derived from matching local processes, project paths, and recent transcript activity, and the UI labels the source.
- API-equivalent estimates are for comparison only. They do not represent subscription spend, credits, discounts, taxes, regional pricing, or an actual provider invoice.
- Storage categories are lower bounds for successfully scanned named paths. Permission failures and unscanned system data remain in the disclosed unclassified amount.
- Real user-file deletion, unrelated live-process termination, Docker volume deletion, and manual fan writes were not executed merely to produce release evidence. Safety and parsing paths are covered by tests, while these live destructive paths remain manual verification items.
- No automated pixel-diff baseline is configured; visual verification was performed by direct screenshot inspection.

## Install

1. Download the DMG or ZIP below.
2. Move `MacDashboard.app` to Applications.
3. If macOS blocks the first launch, use **System Settings → Privacy & Security → Open Anyway**.
4. Install the privileged fan helper only if manual RPM control is required. Fan readback and automatic macOS control remain available without enabling manual mode.
