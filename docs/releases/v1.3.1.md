# MacDashboard v1.3.1 — Verified Core Coverage

MacDashboard v1.3.1 packages the trustworthy-dashboard behavior from v1.3.0 together with a behavior-focused expansion of the native test suite. It is a patch release: the visible interface and the eight public screenshots are unchanged.

## Highlights

- Raised combined source line coverage from **71.04% (4,704 / 6,622)** to **95.63% (6,364 / 6,655)**.
- Expanded the native suite from **71** to **104** passing tests.
- Added behavior coverage for AI provider parsing, token and price policy, project/session hierarchy, Active/Recent/History reconciliation, storage measurement and cleanup boundaries, live read-only metrics, named hardware readings, process attribution, lag diagnosis, fan-helper socket communication, and privileged-helper success and failure outcomes.
- Added internal dependency-injection seams for fan socket I/O, privileged-helper command execution, and process sampling. Existing production callers still use the same shared clients and default live implementations.
- Removed an unreachable lag-severity branch after proving every reachable score/cause combination; the severe user-facing verdict remains covered by combined critical signals.

## Verification performed

- Native test suite: **104 tests passed, 0 failed** with coverage enabled.
- Combined source line coverage: **95.63% (6,364 / 6,655 lines)**, above the repository's 95% policy.
- Release build: succeeded with `CFBundleShortVersionString = 1.3.1`.
- Code signature: the app inside both DMG and ZIP passed `codesign --verify --deep --strict`.
- Packaging: both archives were extracted or mounted and their embedded app version was read back as `1.3.1`.
- Documentation validation: README image targets resolve to eight 1440 × 1050 PNG files. No UI source changed in this patch, so the previously inspected v1.3.0 screenshots remain the applicable visual evidence.

## Evidence boundaries and known limits

- The downloadable app is ad-hoc signed and **not Apple-notarized**. macOS may require **System Settings → Privacy & Security → Open Anyway** on first launch.
- API-equivalent AI estimates are comparisons derived from recognized models, provider-reported token fields, and the versioned rate table. They are not subscription spend, credits, discounts, taxes, or an actual provider invoice.
- Temperature source availability and point counts vary by Mac model and OS.
- Storage categories remain lower bounds for successfully scanned named paths; permission failures and unscanned system data remain in the disclosed unclassified amount.
- Real user-file deletion, unrelated live-process termination, Docker volume deletion, and manual fan writes were not executed merely to produce release evidence. Their safety and parsing paths are covered with isolated tests, while live destructive acceptance remains manual.
- No automated pixel-diff baseline is configured. This patch does not change UI source; the existing eight-tab visual inspection remains the latest UI evidence.

## Install

1. Download the DMG or ZIP below.
2. Move `MacDashboard.app` to Applications.
3. If macOS blocks the first launch, use **System Settings → Privacy & Security → Open Anyway**.
4. Install the privileged fan helper only if manual RPM control is required. Fan readback and automatic macOS control remain available without enabling manual mode.
